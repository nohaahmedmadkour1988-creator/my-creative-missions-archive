THE BRAND SAVER — GITHUB PAGES PACKAGE

IMPORTANT: Upload these extracted FILES into your existing Creative Archive folder on GitHub. DO NOT upload the ZIP as a ZIP file.

1. Extract Brand_Saver_GitHub_Pages_Package.zip on your laptop.
2. In your GitHub repository, open the existing Creative Archive folder (or the folder containing your existing Brand_Saver_Creative_Archive.html).
3. Choose Add file > Upload files. Drag ALL files from inside this package into that folder, including all brand_saver_media_*.js files and brand_saver_video.mp4.
4. Commit changes. If asked to replace Brand_Saver_Creative_Archive.html, replace the old version.
5. Under repository Settings > Pages, check the publishing source is the branch and folder that contain your website.
6. Use the PUBLISHED GITHUB PAGES URL, NOT the github.com/.../blob/.../ URL.

The flipbook still contains 176 pages, 155 screenshots, 36 in Etoile, and one video.
This package leaves your site's existing index.html alone.

If opening locally, double-click Brand_Saver_Creative_Archive.html from the EXTRACTED directory, with the .js files beside it.

If a local file opens but the Pages site gives a DNS 'can't reach' error, the issue is with the published domain or Pages settings, not the content. Share the actual Pages URL for specific troubleshooting.
